# Application artwork

The application temporarily uses the official DeepSeek Harness desktop artwork at the user's request:

- `dsh-official.png`: upstream `apps/desktop/resources/icon.png`
- `dsh-windows.png`: upstream `apps/desktop/resources/icon-windows.png`
- `dsh-macos.png`: upstream `apps/desktop/resources/icon-macos.png`

Source: https://github.com/deepseek-ai/deepseek-harness/tree/fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159/apps/desktop/resources

Linux, Windows, window chrome and tray use the rounded Windows artwork. macOS uses its inset rounded artwork. The original square artwork remains as a source reference.
